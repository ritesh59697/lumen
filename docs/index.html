What it does

Two things that usually need two apps.

Plays the file you have

Built on libmpv — the engine behind mpv — so odd containers and old codecs open without hunting for a codec pack. Decoding is hardware-accelerated.

Writes the missing subtitles

One button. Lumen pulls the audio, runs Whisper on your own machine and loads the result onto the video. An hour of speech takes about two minutes on Apple silicon.

Lets you fix what it got wrong

Speech recognition mishears names and technical words. The editor sits beside the video with the current line highlighted — correct the text, nudge the timing, export the SRT anywhere.

Watch while it works

Captions appear before the transcription finishes.

Audio is transcribed in order, so a job that is half done already covers the first half of the video — the part you are watching. Subtitles show up about thirty seconds in and keep extending. You will not catch up to it.

How a caption gets made

Every step runs on your machine.

Lumen makes exactly one network request in its life: downloading the speech model the first time you ask for captions. After that you can stay offline permanently.

1Audio extracted from the videoFFmpeg
2Converted to 16 kHz monowhat Whisper needs
3Silence skipped, speech transcribedwhisper.cpp
4Timings cleaned, long lines wrappedso it reads
5Loaded onto the video as SRTyours to keep

Formats

If mpv plays it, Lumen plays it.

mp4mkvavi webmmovflv wmvm4vmpg mpegtsm2ts 3gpogv

Existing subtitle files load too — SRT, VTT, ASS and SSA — and anything sitting next to the video is picked up automatically.
