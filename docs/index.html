First time you open it: right-click the app and choose Open, then confirm. Lumen isn't signed with a paid Apple developer certificate, so macOS asks once. After that it opens normally.

What it does

Plays the file you actually have

Built on libmpv — the engine behind mpv — so odd containers and old codecs open without hunting for a codec pack. Decoding is hardware-accelerated.

Writes the subtitles that are missing

One button. Lumen pulls the audio, runs OpenAI's Whisper model on your own machine, and loads the result onto the video. On Apple silicon it uses the GPU: ten seconds of speech takes about a second and a half.

Lets you fix what it got wrong

Speech recognition misses names and mishears words. The editor sits beside the video with the current line highlighted — correct the text, nudge the timing, split a line that ran on, then export the SRT anywhere.

How a caption gets made

1Audio extracted from the videoFFmpeg
2Converted to 16 kHz monowhat Whisper needs
3Silence skipped, speech transcribedwhisper.cpp
4Timings cleaned, long lines wrappedso it reads
5Loaded onto the video as SRTyours to keep

Every step is a local process. Lumen makes exactly one network request in its life: downloading the speech model the first time you ask for captions. After that you can stay offline permanently.
